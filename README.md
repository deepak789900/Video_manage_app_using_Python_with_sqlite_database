# 🎥 YouTube Video Manager (SQLite3)

A simple **command-line application** written in Python that helps you manage your favorite YouTube videos using **SQLite3**.  
You can **list, add, update, and delete** video records with ease.

---

## 📌 Features
✅ Create a SQLite database (`youtube_videos.db`) automatically  
✅ Add new YouTube videos with name & time  
✅ View a list of all saved videos  
✅ Update video details (name or time)  
✅ Delete videos by ID  
✅ Simple command-line menu interface  

---

## 🛠️ Technologies Used
- **Python 3**
- **SQLite3** (built-in Python library)
